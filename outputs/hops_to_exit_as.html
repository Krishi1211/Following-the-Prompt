First-Mile AS Exit Count

Measures the average number of network hops required to leave the source ISP's autonomous system (ASN) toward each LLM service. Higher values indicate deeper routing paths inside the originator's internal backbone before handoff. Anomalies show traces that never exited the source ASN.
